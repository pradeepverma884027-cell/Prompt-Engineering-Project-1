# Prompt Engineering Project 1

Zero-Shot and Few-Shot Data Extraction using Prompt Engineering.

## Features

- Zero-Shot Prompting
- Few-Shot Prompting
- Delimiter-Based Prompt Design
- JSON Schema Enforcement
- Null Fallback Logic
- Deterministic Outputs
- Streamlit Demonstration

## Tech Stack

- Python
- Streamlit
- JSON
- Prompt Engineering
- GitHub
